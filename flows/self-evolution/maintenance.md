# 自进化维护与卫生（E02）

当前为人工/owner 流程；精确内容 hash 去重不等于语义去重，不自动晋升。

## 角色与周期

- **owner**：AI 平台团队指定一人；对合并、过期归档、晋升/拒绝负责。
- **周期**：每周检查 staged 候选与反馈；每月做一次 stale/重复清理；跨日调度由部署 owner 另行登记。

## 检查清单

1. **重复**：同一 lane 下标题/正文语义重复的候选，保留最早或最完整一条，其余标 `superseded` 并写明理由。
2. **过期**：超过 45 天未处理、且无消费方/无证据的候选，标 `stale` 或归档；不静默删除。
3. **证据**：晋升候选必须有跨 session 证据、失败模式、owner、边界与目标范围；用 `gates/gate.py promotion` 做字段/hash/git/范围检查。
4. **合并**：合并多个候选时保留来源 session 列表与合并理由；合并结果仍需人批准。
5. **回滚**：误晋升按 git 历史回滚，并更新 INDEX/游标；保留复盘记录。

## 不做的事

- 不按精确 hash 去重代替语义判断。
- 不自动修改资产状态、不自动外发、不自动批准。
- 没有真实使用压力时不建 curator 平台；先维持本清单与人工记录。
