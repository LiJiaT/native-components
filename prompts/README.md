# prompts/

可复用的提示词模板。一个模板一个文件，文件名用 kebab-case。

## 当前模板

| 模板 | 版本 | 说明 |
|---|---|---|
| [`system-prompt-starter`](system-prompt-starter.md) | 0.1.0（experimental） | 可移植全局系统提示词起点：子代理委派、长跑后台任务、路径解析、跨 session 工作线、外发人工卡点；用 `<...>` 与 `%USERPROFILE%` 占位。 |

> 已知缺口：该模板当前用 `<...>` 占位而不是 `{{variable}}`，也尚未附正例/反例；后续按下方要求补齐后再升 1.0。

## 模板要求

- 标明用途、适用模型/场景、输入变量（用 `{{variable}}` 占位）。
- 给出期望输出格式与验收标准。
- 附带至少一个正例；有边界条件时附反例。
- 不写死模型名、密钥、内部链接等易变信息。
