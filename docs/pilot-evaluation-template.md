# 资产消费试点复盘模板（F03）

用途：记录一条真实、非 synthetic 资产在项目中的使用前后变化。不是 KPI 平台，也不以 fixture/结构测试代替工程收益。

- 资产：`asset_id` / 版本 / record 不可变正文 hash
- 项目与 owner：
- 试点周期：
- 使用前：完成同类任务耗时、返工次数、追问次数、质量问题的记录方式
- 使用方式：检索→适用性→引用版本→安装/加载→消费验收的实际步骤
- 使用后：同一口径的耗时、返工、追问、质量问题
- 消费验收证据：触发方式、输入、预期、实际结果、失败处理
- 未解决问题与反馈单：
- 结论：保留 / 修订 / 退役；下一步 owner 与日期

注意：没有基线就不填“提升百分比”；样本不足时只写观察，不写收益结论。
