# flows/

端到端 AI Native 工作流。一个流程一个子目录，描述多个技能/组件如何协作、在哪些点需要人批准、阶段之间交接什么。

## 建议结构

```
<flow-name>/
├── README.md        # 目标、适用场景、前置条件
├── flow.md          # 阶段划分、输入输出、交接契约
├── gates.md         # 人工审批点与确定性校验闸门
└── examples/        # 示例运行记录（脱敏）
```

## 编写要求

- 每个阶段写清：输入、执行者（人/技能）、输出、完成判定。
- 交接物必须是可判定的文件或状态（如 `approved asset record`），不能是“口头确认”。
- 明确卡点：未经人的批准，流程不得进入下一阶段。
- 写清失败与回滚路径。
